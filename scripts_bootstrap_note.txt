From the project root, run scripts/bootstrap_android.ps1 on Windows or scripts/bootstrap_android.sh on Linux/macOS after installing Flutter and Android Studio. The script generates the Android wrapper, sets minSdk 24 for flutter_secure_storage, enables Internet access, fetches Dart dependencies, and runs flutter analyze/flutter test. If those pass, run flutter build apk --release. No APK is included until a real build succeeds.
